# StayEasy Helper

A guest assistant prototype for StayEasy, a fictional holiday-let brand. Open `index.html` in any browser. It's a single file with no build step.

**What it shows:** a messaging-style chat with booking cards, carousels, a mini calendar, a cart, refund progress steps, an urgent-help card, live agent handover, and an "Agent view" toggle showing what the support team sees.

**Demo setup:** the date is fixed at Thursday 4 February 2027. The guest is Priya Patel, with two upcoming stays and one past stay. All properties, bookings and people are invented.

**Personalise it:** edit the `CONFIG` block at the top of the script in `index.html` to set your name, LinkedIn URL and the four evidence lines shown in the Design notes panel.
